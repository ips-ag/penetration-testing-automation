# penetration-testing-automation
Penetration Testing Automation internal project
### 1️⃣ [OWASP ZAP](./src/zap-proxy/README.md)
For automated penetration testing during deployment and testing of live applications, OWASP ZAP is the better choice. It will allow you to run black-box or gray-box tests, identify vulnerabilities, and generate meaningful reports that can be used in your CI/CD pipeline for ongoing security testing.
### 2️⃣ [OWASP Threat Dragon](./src/threat-dragon/README.md)
Threat Dragon is better suited for early-stage threat modeling. If you're looking for a tool that helps you design secure systems and assess risks during the architecture phase, it would be useful. However, it doesn't replace automated testing or vulnerability scanning like ZAP.
